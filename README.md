# Carbon Footprint

A web application for calculating and tracking carbon footprint emissions. Built with HTML frontend and Python backend.

## Overview

Carbon Footprint is an interactive tool designed to help users understand and monitor their environmental impact by calculating carbon emissions from daily activities.

## Technologies

- **Frontend**: HTML5
- **Backend**: Python
- **Purpose**: Environmental impact tracking and analysis

## Getting Started

### Prerequisites

- Python 3.7+
- A modern web browser

### Installation

Clone the repository:

```bash
git clone https://github.com/rizwana25/Carbon-Footprint.git
cd Carbon-Footprint
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

### Running the Application

Start the backend server:

```bash
python app.py
```

Then open your browser and navigate to `http://localhost:5000` (or the configured port).

## Features

- Calculate carbon emissions from various activities
- Track personal carbon footprint over time
- View detailed emission reports
- Get recommendations for reducing carbon impact
- User-friendly interface

## Usage

1. Open the application in your browser
2. Enter your daily activities and consumption data
3. View your calculated carbon footprint
4. Get insights and recommendations for sustainability
